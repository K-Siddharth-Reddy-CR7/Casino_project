# 🎰 Neon Vegas Casino

A full-stack online casino web application built using **Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript**. The project provides users with a modern casino experience featuring secure authentication, wallet management, and interactive casino games.

## 🚀 Live Demo

**Website:**    https://casino-project-eight.vercel.app/#/

## 📂 GitHub Repository

https://github.com/K-Siddharth-Reddy-CR7/Casino_project

## ✨ Features

* User Registration & Login
* Secure Authentication
* Wallet Management (Deposit & Withdraw)
* Interactive Casino Games
* Transaction History
* Responsive User Interface

## 🛠️ Tech Stack

**Frontend**

* HTML
* CSS
* JavaScript
* Bootstrap

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

**Deployment**

* Google Cloud Run

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/K-Siddharth-Reddy-CR7/Casino_project.git
```

Navigate to the project folder:

```bash
cd Casino_project
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

Open your browser and visit:

```text
http://localhost:3000
```
